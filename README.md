# Apply Scout

**Turn your Markdown profile into job research and an application plan.**

**Markdown 프로필로 채용 공고를 찾고 지원 계획까지 정리하세요.**

[English](docs/en/README.md) · [한국어](docs/ko/README.md)

Provide your profile, optional portfolio, and a list of recruiting sites. Codex or Claude Code
researches openings; Apply Scout creates a deadline-ordered Markdown tracker with links to
individual role analyses, preserving your application status and notes across runs.

프로필·선택 포트폴리오·조사 사이트 목록을 넣으면 Codex 또는 Claude Code가 공고를 조사합니다.
Apply Scout는 마감일순 지원표와 공고별 분석을 만들고 재실행 시 지원 상태와 메모를 보존합니다.

## Status / 현재 상태

**v0.1.0 · CLI MVP · Python 3.10+ · No additional Python packages**

English and Korean documentation and translated examples are available. CLI messages and fixed report
labels currently use Korean. The web interface and full live-site integration checks are still pending.
Examples are fictional and do not represent actual openings.

영어·한국어 문서와 번역 예시를 제공합니다. CLI 안내와 자동 생성 보고서의 고정 문구는 현재
