# 기여 가이드

[English](../en/contributing.md) · **한국어**

버그 수정, 사이트별 조사 사례, 문서 개선을 환영합니다.

1. 재현 가능한 이슈 또는 범위가 작은 변경을 준비해 주세요.
2. Python 3.10 이상과 표준 라이브러리를 사용합니다.
3. 상태 보존·마감일·URL 처리 변경은 해당 실패 사례를 테스트에 추가해 주세요.
4. `python3 -m unittest discover -s tests -v`를 실행해 주세요.
5. PR에는 문제, 변경된 동작, 검증 내용을 적어 주세요.

실제 이력서, 개인 연락처, 인증 정보는 예시·이슈·테스트에 포함하지 마세요.
예시 공고는 가상임을 표시하고 example.com 도메인을 사용합니다.

## 문서 언어

`docs/en/`과 `docs/ko/`의 대응 문서와 번역 예시를 함께 관리합니다.
상대 링크와 언어 전환 링크를 유지하세요. 명령어·파일명·출력 규격 키·상태 값·메모 보존
마커는 현재 구현과 호환되도록 유지합니다.

`docs/research-instructions.md`는 실행 시 읽는 조사 지침 원본입니다. 두 언어의 조사 가이드도
같은 내용을 유지하세요. `AGENTS.md`와 `CLAUDE.md`는 AI 도구가 읽는 파일로 유지합니다.
기본 입력 양식과 보고서 생성기는 아직 한국어를 사용합니다. 영어 보고서 생성 기능이 구현되기
전에는 번역 예시를 자동 생성된 영어 보고서로 설명하지 마세요.
